Quick start

About 15 minutes, once. You need a Mac or Windows PC, a Roblox account, and a paid Claude plan that includes Claude Code (Pro, Max, Team or Enterprise; the free plan doesn't).

  1. Download and unzip the kit

    Get it from the store; your purchase page has the download. Mac: double-click the zip. Windows: right-click it › Extract All (don't open files from inside the zip).

  2. Double-click “Start Here”

    Mac: Start Here.command. The first time, macOS may say it can't be opened; right-click it › Open › Open.
    Windows: Start Here.bat. If a blue SmartScreen box appears: More info › Run anyway.

    It installs Claude Code if you don't have it, opens the Roblox Studio download page if you need it, asks your game's name, makes its folder in Roblox Games, and opens the setup helper. Sign in to Claude when the browser asks, and say Yes when Claude asks whether to trust the folder.

  3. Answer the setup helper

    It works one step at a time and checks each one itself. It will ask what your game is about, who'll play it, and your Roblox username (to make you the safety moderator).

Self-adapting loops

Once people are playing, the game can keep improving itself. Type this in Claude Code and leave it open:

/loop 1h /adapt

Every hour, one /adapt pass runs four loops. Press Esc to stop. It runs only while Claude Code is open (up to 7 days per loop) and uses your Claude plan while it works.

LoopWhat it does by itselfIts limits
LearningWrites what worked, what broke and your preferences to docs/lessons.md after every feature, fix and pass. Every new session starts by reading it.No player names or chat text. You can edit or delete any line.
SafetyReads the incident log, spots new spellings people use to sneak contact requests past the filter, and adds them. Every server picks them up within a minute.Stricter only: it can add terms, never remove them. A term that would block everyday chat is refused.
Game tuningReads anonymous play counts (where players fall, quit, get stuck or breeze through) and adjusts rewards, timings and difficulty live.At most 2 knobs per pass, at most 25% each, always within safe bounds, with 30+ events of evidence. Every change is logged and can be reset.
Playtest and fixStarts the game, reads errors, fixes them, tests again.Never edits the safety system.

To make this possible unattended, the kit lets Claude run Luau and edit scripts in Studio without asking. The README shows how to switch that back.

Manual setup (only if the helper gets stuck)

Everything the helper does, by hand. About 30 minutes. Mac commands are shown; Windows differences are noted. Each part ends with a check.

1. Install

  • Roblox Studio, latest version (open it once; it updates itself).
  • Claude Code, installed and signed in. In Terminal (Mac) or PowerShell (Windows), claude --version should print a version.
  • A Roblox place you own. A fresh Baseplate is fine.
  • Optional: git, for undo history.

2. Unzip the kit into a project folder

Download the kit from your purchase page into your Downloads folder, then:

mkdir -p ~/Projects/my-game
cd ~/Downloads
unzip roblox-teen-kit.zip
cp -R roblox-claude-kit/. ~/Projects/my-game/
cd ~/Projects/my-game
ls -a
git init && git add -A && git commit -m "Starter kit"   # optional

The /. copies hidden files too (.claude, .mcp.json). In Finder, press Cmd + Shift + . to see them.

Windows: right-click the zip › Extract All, move the contents into %USERPROFILE%\Projects\my-game, then rename .mcp.windows.json to .mcp.json (replace the Mac one).

ls -a lists .claude, .mcp.json, CLAUDE.md, docs, src.

3. Connect Claude Code to Studio

  1. Open your place in Studio. Go to Assistant › ⋯ › Manage MCP Servers and turn on Enable Studio as MCP server.
  2. In the same panel, keep Quick Connect for Claude Code off. The kit's own .mcp.json connects instead, under the name Roblox_Studio, which the kit's permissions and helpers expect. Two connections also load every tool twice and waste tokens.
  3. In Terminal: cd ~/Projects/my-game then claude. Approve the project's MCP server if asked.
  4. Type /mcp.
/mcp shows Roblox_Studio connected, and Studio's panel shows a green indicator. Ask Claude: “List the top-level services in my place with search_game_tree, depth 1. Names only.”

4. Prepare the place

  1. File › Publish to Roblox. Saving player data and safety logs only works in a published place.
  2. Home › Game Settings › Security › Enable Studio Access to API Services, then Save.
  3. Complete the Maturity & Compliance questionnaire for your experience in the Creator Dashboard, truthfully. Without it, your game shows as “Content May Vary” and isn't available to under-16s by default.

5. Get the code into Studio

Path A, Rojo (recommended). Keeps scripts as files with history.

curl -sSf https://raw.githubusercontent.com/rojo-rbx/rokit/main/scripts/install.sh | bash
# close and reopen Terminal, then:
cd ~/Projects/my-game
rokit init
rokit add rojo-rbx/rojo
rokit add Kampfkarren/selene
rokit add JohnnyMorganz/StyLua
rojo plugin install
rojo serve

Leave that window running and open a second Terminal tab for claude. In Studio: Plugins › Rojo › Connect. From now on, edit scripts as files in src/, never inside Studio; Rojo overwrites Studio-side edits.

Windows Rokit install (PowerShell):

Invoke-RestMethod https://raw.githubusercontent.com/rojo-rbx/rokit/main/scripts/install.ps1 | Invoke-Expression

Path B, straight into Studio. Ask Claude to create each script from src/ with multi_edit, creating parent folders first. The README in the kit lists the exact destinations.

Explorer shows ServerScriptService › Server (Main, Lib, Safety, Services), ReplicatedStorage › Shared, and StarterPlayerScripts › Client.

6. Fill in the two files that are yours

  1. CLAUDE.md: replace every bracket under Game (genre, platforms, server size, round length). With Rojo, add under Hard rules: - Rojo is running: edit files in src/ only; never multi_edit a synced script. Keep it under ~60 lines.
  2. src/server/Safety/SafetyConfig.luau: add your Roblox UserId (the number in roblox.com/users/<UserId>/profile) and any trusted adult moderators to ModeratorUserIds.
No brackets left under Game; your UserId is in ModeratorUserIds. Run /clear in Claude so it reloads the brief.

Saving tokens

Every message re-sends the whole session, so long chats cost more each turn. These habits matter most:

  • One feature per session, ending with /handoff and /clear. The handoff rewrites “Current state” in CLAUDE.md so the next session starts small.
  • Let Claude read, don't paste. It reads scripts, searches code and reads the console through Studio. Pasting whole scripts is the biggest waste.
  • Name the script. “Look through the project” is the most expensive request there is.
  • Ask for changed lines only. No full-file rewrites, no explanations you didn't ask for.
  • Screenshots only for visual bugs. Images cost far more than text.
  • Check /context. Past about half full, hand off and clear.

Teen safety

This is the Teen Build Kit: for games made by and for players aged 13 to 17. It opens up the kinds of games teens actually play (combat, horror, trading, typed names) and keeps every protection against adults trying to reach them. The family handbook further down still applies: read sections 4 to 8 there for reviewing incidents, what to do if you see something, and evidence.

Who uses this kit

Claude accounts are for adults (18+). A parent or guardian owns the Claude account, runs setup, and is the game's safety moderator. The teen designs and builds alongside them. The teen can't use Claude on their own.

What never changes

  • Blocked in chat: phone numbers, addresses, emails, school; moving to Discord, Snapchat, Instagram and other apps; "where do you live" and meet-up asks; secrecy ("don't tell your parents"), "are you alone", and requests for pictures. The tricks people use to sneak these past filters (spaced letters, number swaps, look-alike letters, spelled-out numbers) are caught.
  • Repeat offenders are paused and remembered across every server of the game.
  • Report a problem button, the incident log, and live moderator alerts.
  • No private spaces where two players can be alone, no private messaging, no links or social handles, no uploads.
  • Not allowed at all (Roblox 18+ or not legal or allowed for minors): romance or dating, alcohol or drugs, strong language, gambling, paid random items (loot boxes), and gore.

Trading, safely

Grooming often starts with gifts. So in the teen kit: - A trade needs something on both sides. One-way "trades" are gifts and are blocked. - Both players must accept; any change to an offer resets both accepts. - Lopsided trades (one side worth 4 times the other or more) go through, but are logged and you get an alert. One is usually a friend being generous. A pattern of one account making generous trades with younger players is a warning sign: check /incidents. - Each player can trade at most once every 20 seconds. Every trade is in the log.

Robux items

ShopService sells fixed items only: coin packs and perks like Double Coins. Every item gives exactly what its name says. No loot boxes, spins or mystery items bought with Robux.

Your content questionnaire

Combat with damage, blood effects and horror change your answers to Roblox's Maturity & Compliance questionnaire. Answer it honestly whenever you add them; the game will usually be labelled Moderate, which Roblox shows to players 9 and up in its Select setting and to everyone 16 and up.

Opening the game

Same steps as the family kit (section 3b below): finish the questionnaire and /safety-review, open to Friends first, then to everyone when you're ready. Family mode (guest list only) stays on until you choose.

The protections in detail

Many Roblox players are children, and some adults use games to reach them. This kit adds a second layer of protection on top of Roblox's own, documents anything worrying so it can be reported, and tells you exactly what to do.

What Roblox already does

  • Age checks for chat. Since January 2026, every user worldwide must complete an age check (face estimation, or ID for 13+) before chatting.
  • Age-based chat. By default players chat only with their own age group and the ones directly above and below (under 9, 9–12, 13–15, 16–17, 18–20, 21+). Chat is off for under-9s unless a parent turns it on.
  • Filtering and moderation. Chat is filtered, most personal info is blocked, and reports reach Roblox's moderators.

Limits

The kit can't hear voice chat or see images, and determined people evade keyword checks. A quiet log means nothing was caught, not that nothing happened. Roblox's reporting and moderation remain the main line of defense.

Review the log

At least weekly, and the same day an alert or report comes in. Easiest: type /incidents in Claude. It explains the log in plain language and tells you what to do. By hand, in Studio's command bar:

local L = require(game.ServerScriptService.Server.Safety.SafetyLog)
L.printRecent(7)          -- last 7 days, newest first
L.forUser(123456789, 30)  -- everything involving one UserId
L.exportCsv(7)            -- CSV to copy into a report

Patterns matter more than single messages: one account flagged in several servers, or with several different children, is a strong signal. A child sharing their own details by mistake has already been protected; no further action is needed.

Evidence rules

  • Do record usernames, UserIds, times (UTC), the server ID and the exported log rows. That's what investigators need.
  • Never download, screenshot, save or forward a sexual image or video of a child, even to report it. Possessing or sharing it is a crime. Describe where you saw it and report that.
  • Never contact or confront the suspect, pretend to be a child to investigate, or name them publicly. It can warn them and put a child at more risk.
  • Don't delete records about a reported case. Keep the export in secure storage until the authorities say otherwise.
  • If you know the child's parent personally, tell them privately and give them the hotline details.

Privacy of the log

The log holds children's messages. Only trusted adult moderators should see it. It deletes itself after 30 days; keep exports only for reported cases, never send logs to Discord or other outside services, and use them for nothing but safety.

For parents

Share this section with any parent whose child plays.

  1. Link your account. On your child's account: Settings › Parental Controls › Add parent, then enter your email. You'll verify your age with ID or a credit card.
  2. Communication. Parental Controls › Settings you manage › Communication: turn Experience Chat and Direct Chat on or off, and choose who your child can chat with.
  3. Content. Content restrictions › Content maturity: set the level you're comfortable with. You can also block specific games.
  4. Spending and screen time. Set a monthly spending limit with alerts, and a daily screen-time limit.
  5. Connections. Review your child's connections; block and report anyone you don't recognize.

Warning signs worth a calm conversation

  • A new online “friend” your child won't talk about.
  • Gifts of Robux or items from someone online.
  • Being asked to move to another app, or to keep secrets.
  • Sudden secrecy about the device or time spent online.

Tell your child: they won't be in trouble for telling you. Show them the Report and Block buttons, and agree they'll come to you if anyone makes them uncomfortable.
